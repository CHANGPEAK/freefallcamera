# 自由落體影片分析系統　離線版使用說明書

適用版本：離線版（free\_fall\_recorder.html，單一 HTML 檔，不需網路）；線上版另有專用說明書｜2026 年 11 月

## 1. 系統簡介

本系統用手機拍攝物體由靜止自由落下的影片，直接在影片上逐幀標記物體位置，自動計算經過時間與落下距離，並畫出：

- 落下距離—時間圖（含二次曲線擬合與公式）
- 速度—時間圖（含公式）
- 加速度—時間圖（含公式），並由擬合結果算出重力加速度 g

操作流程共四步：**拍攝或載入影片 → 校正比例尺 → 標記物體位置 → 檢視報告／儲存**。

## 2. 開啟方式與注意事項

- **取得與開啟**：把 free\_fall\_recorder.html 存到電腦或手機，用 Chrome 或 Safari 開啟即可，不需要網路，也不需要安裝。
- **功能範圍**：有「① 校正」「② 量測」「③ 報告」三個分頁，可匯出 CSV；沒有班級組別、PDF、雲端儲存與管理者頁面，這些是線上版功能，請見[線上版使用說明書](https://claude.ai/artifact/AC2XYRfyywjGTWDX3hQcRd)。
- **資料不會自動儲存**：重新整理或關閉網頁後，影片、校正與標記都會消失。完成後請先按「匯出 CSV」存檔。
- **相機限制**：網頁直接開相機通常需要 https 或 localhost；直接開啟本機檔案時，手機上多半無法使用，請改用手機相機 App 錄影，或選擇已有影片。

## 3. 拍攝前準備

**器材**：手機（建議可拍慢動作）、腳架或可固定手機的支架、已知長度的比例尺（公尺尺、捲尺）、與背景對比明顯的落體。

**拍攝要點**：

1. 手機固定不動，鏡頭水平、正對落下平面，拍攝時不要移動或變焦。
2. 比例尺豎直放在落下路徑旁，與落體在同一個深度（離鏡頭一樣遠），並完整入鏡。
3. 光線充足、背景單純。光線越亮，快門可以越快，動態模糊越少。
4. 落體由靜止放開，不要用力推或丟；下落路徑與落地點都要在畫面內。
5. 幀率越高越準：建議 60 fps 以上，120 或 240 fps 更好。

## 4. 畫面總覽

頂端有三個分頁：

- **① 校正**：校正比例尺（把像素換算成公尺）。
- **② 量測**：拍攝或載入影片，逐幀標記物體位置。
- **③ 報告**：查看圖表與公式，並匯出 CSV。

開啟後預設在「② 量測」，因為要先有影片，才能校正與標記。

## 5. 步驟一：拍攝或載入影片（② 量測頁）

在頁面上方的「拍攝／載入影片」區塊，有三種方式取得影片。

### 方式 A：網頁直接拍攝

1. 按「開啟相機」並允許相機權限。
2. 選擇解析度（480p／720p／1080p）與目標幀率（30／60／120／240）。高幀率通常需要較低的解析度，建議先試 720p。
3. 畫面左上角會顯示「實測 xx fps」，下方文字會顯示相機實際輸出的解析度、幀率與鏡頭上限。若實際幀率低於目標，表示瀏覽器沒有提供，請降低解析度再試，或改用方式 B。
4. 需要時可按「切換前後鏡頭」。若裝置支援，會出現「自動曝光」選項：取消勾選後可用滑桿手動調快門，顯示為「快門約 1/N 秒」，N 越大快門越快，動態模糊越少，但畫面會變暗。
5. 按「● 開始錄影」，畫面左上角會顯示經過秒數；放開落體後按「■ 停止並分析」。
6. 錄影結束會自動載入影片、偵測幀率，並收起拍攝區塊。

注意：網頁直接開相機需要 https 或 localhost 網址。直接開啟本機檔案時，常會被瀏覽器封鎖；若出現「無法開啟相機」，請改用方式 B 或 C。

### 方式 B：用手機相機 App 錄影

按「用手機相機 App 錄影」會開啟手機內建相機。這是使用原生慢動作（120／240 fps）最穩定的方式。拍完回到網頁即自動載入。

### 方式 C：選擇已有影片

按「選擇已有影片」，從手機或電腦選取影片檔。

### 幀率與慢動作倍數

載入影片後，系統會自動偵測幀率並填入「影片幀率 fps」，下方顯示「計算用幀率」與每幀間隔（毫秒）。時間由這個數字計算：經過時間 = 幀數 ÷ 計算用幀率。

- 手機慢動作影片匯入後，偵測到的常是 30 fps（影片被拉長播放）。請在「慢動作倍數」填入倍數（例如 240 fps 拍攝、30 fps 播放，填 8），計算用幀率就會是正確的 240 fps。
- 偵測不準時，可手動修改幀率欄位。換影片後需要重新校正。

## 6. 步驟二：校正比例尺（① 校正頁）

1. 進入「① 校正」頁，用滑桿或「上一幀／下一幀」按鈕，找出比例尺最清楚的一幀。
2. 在畫面上依序點比例尺的兩端。比例尺越長越準，建議佔畫面高度三分之一以上。
3. 在右側輸入兩點之間的實際長度（單位：公分）。
4. 系統立即顯示比例尺（1 像素 = 幾 mm）。
5. 按「驗證量測」，再點畫面上另一段已知長度的兩端，系統會顯示量到的長度，誤差應小於 2%；否則按「重新點選」重新校正。
6. 完成後按「前往量測頁」。

沒有校正時，位移以像素顯示，也無法換算 g。

## 7. 步驟三：標記物體位置（② 量測頁）

1. 用滑桿與逐幀按鈕（−10、◀、▶、+10）找到物體剛要掉落的那一幀。桌機也可用鍵盤的 ← → 逐幀移動。
2. 點物體中心，這一點就是起點（t = 0，位移 = 0）。
3. 每次點擊後會自動前進指定的幀數（「標記後前進」，預設 1 幀；影片幀率很高時，可設為 2～5 幀以減少點擊次數）。
4. 一路點到物體落地前最後一幀。每次都盡量點同一個特徵位置，例如球的中心。
5. 右側表格會即時列出幀、時間 t 與位移 d。點錯時按「復原最後一點」；全部重來按「清除標記」。在同一幀重新點擊會取代原本的點。
6. 建議至少標記 10 個點。

iPad 提示：影片畫面高度已限制在螢幕內，不需要上下捲動；橫放時影片在左，設定與表格在右。

## 8. 步驟四：檢視報告（③ 報告頁）

### 圖表與公式

- **落下距離—時間**：橘點是標記數據，綠線是擬合曲線，公式為 d = a t² + b t + c，並顯示 R²（越接近 1 擬合越好）。
- **速度—時間**：由距離公式對時間微分得到 v = 2a t + b；圖上的點是相鄰標記點的差分速度。b 是起點的初速度，理想上接近 0。
- **加速度—時間**：a = 2a，是一個常數；虛線是 g = 9.8 的參考值。圖上的點是二次差分，雜訊很大，只看趨勢，數值請以擬合結果為準。
- 校正後會顯示 g = 2a，以及與 9.80 相差的百分比。

### 擬合方式

- **一般二次**：d = at² + bt + c，至少 3 點。若 b、c 明顯不為 0，通常表示起點沒有點在剛要掉落的那一幀。
- **通過原點**：d = at²，假設起點的時間與位移都是 0。

### 輸出

- **匯出 CSV**：下載幀、時間、距離、速度、加速度，可在試算表軟體繼續分析。離線版不會自動儲存，請先匯出再關閉網頁。

## 9. 常見問題

**相機打不開？**

需要 https 或 localhost；直接開啟本機檔案時，手機上也常被封鎖。請改用「用手機相機 App 錄影」或「選擇已有影片」，也請確認瀏覽器已允許相機權限。

**實際幀率只有 30，拿不到 120／240？**

手機瀏覽器通常只開放 30～60 fps。請降低解析度重試，或用手機相機 App 的慢動作拍攝後再載入，並填入慢動作倍數。

**算出的 g 和 9.8 差很多？**

請依序檢查：

1. 比例尺與落體是否在同一個深度，輸入的實際長度是否正確（單位是公分）。
2. 計算用幀率是否正確（慢動作影片是否填了倍數）。
3. 起點是否點在剛要掉落的那一幀；改用一般二次擬合，看 b、c 是否接近 0。
4. 是否有點錯位置或漏掉幀，可回頭逐幀檢查。
5. 拍攝時手機是否晃動。

**加速度圖的點為什麼那麼亂？**

二次差分會把標記誤差放大很多，這是正常現象。請以距離圖的二次擬合公式與 g = 2a 為準。標記的點越多、涵蓋的時間越長，結果越穩定。

**換了影片，比例尺不見了？**

每支影片都要重新校正，因為拍攝距離與畫面大小可能不同。

## 附錄：公式說明

- 距離：d = a t² + b t + c
- 速度：v = 2a t + b（d 對 t 微分）
- 加速度：a = 2a，為常數（d 對 t 二次微分）
- 重力加速度：g = 2a，標準值約 9.80 m/s²
- 經過時間：t = (目前幀 − 起點幀) ÷ 計算用幀率
